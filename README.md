# ADTV 2 releases

Compiled Windows x64 releases of ADTV, version 2.0 and later.

To install, download `ADTV-<version>-win-x64.zip` from the newest release, extract the complete folder to a permanent location and run `DesktopYamanoteLine.exe`. Existing installations update from the tray.

`SHA256SUMS` lists the SHA-256 of each release file. Update metadata is signed, and the application verifies it before installing an update.
